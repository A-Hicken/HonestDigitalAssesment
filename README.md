# Lincoln Nautilus Landing Page – Assessment

This project is a responsive landing page built as part of a front-end assessment. The goal was to recreate a provided design mockup using HTML, CSS, and basic JavaScript.

## 🔧 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## 📌 Features

- Responsive layout for desktop and mobile
- Hero section with pricing details
- Call-to-action buttons (View Inventory / Contact Us)
- Modal popup for "Offer Details"
- Structured content sections for readability
- Clean and semantic HTML structure

## 📂 Project Structure

├── index.html
├── styles.css
├── script.js
└── README.md

## 🚀 How to Run

1. Download or clone the repository
2. Open the project folder
3. Double-click `index.html` or open it in your browser

## 💡 Notes

- This project focuses on layout accuracy and clean structure based on the provided mockup
- JavaScript functionality is minimal and used for modal interaction
- No external frameworks or libraries were used
